# Barlow fonts

Barlow Regular and SemiBold, and Barlow Condensed Bold and ExtraBold, by
Jeremy Tribby / The Barlow Project Authors. Distributed under the SIL Open
Font License 1.1; see OFL.txt in this directory.

Unmodified TTF files sourced from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/barlow
- https://github.com/google/fonts/tree/main/ofl/barlowcondensed

The Go binary embeds these assets and their license. Pages load fonts from
the same server using `font-display: swap`; no external font service is needed.
The public asset routes remain available during both personal and admin sessions.
